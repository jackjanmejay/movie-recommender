# Dataset Information

## MovieLens Dataset

This folder requires the MovieLens dataset.

### Download Instructions

1. Download from: https://files.grouplens.org/datasets/movielens/ml-latest-small.zip
2. Extract the zip file
3. Place `movies.csv` and `ratings.csv` in this folder

### Note:
The dataset is not included in GitHub due to size. 
When running locally, please download it using the instructions above.
